# Changelog

## Unreleased

- Stopped the public-status card from claiming searches that did not happen. A lookup that read no search result or page (no measured frame, no Tavily key, a failed search, every query refused or stopped before a result list was read, unreadable search results, or an error) used to be recorded as `NO_PUBLIC_FINDINGS`, which reads as "searched and found nothing". It is now `LOOKUP_UNAVAILABLE`, claims nothing either way, and the page says no page was read. The card and its note now list only the queries that were sent; before, a third planned query that the two-search cap never sent was listed as searched. Pages read by the crawl fallback count as read. No task in `eval/results/public_status.json` took a no-read path, so its counts are unchanged; 18 of its rows list an unsent third query, which the README now states. A Grok review of the first version of this fix found the stop, result-list, crawl, and page-text cases. The non-live Python suite is 191 tests and the door e2e suite has 7 tests.
